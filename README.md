# RETAIL INTELLIGENCE

> AI/Data Science powered Retail Decision Intelligence Platform

The complete project is located in [`retail-intelligence/`](./retail-intelligence/).

## Quick Start

### 1. Start Backend (Terminal 1)
```cmd
cd retail-intelligence\backend
.venv\Scripts\activate
python -m uvicorn main:app --reload --port 8000
```
*Or simply run `retail-intelligence\start-backend.bat`*

### 2. Start Frontend (Terminal 2)
```cmd
cd retail-intelligence\frontend
npm run dev
```
*Or simply run `retail-intelligence\start-frontend.bat`*

### 3. Open Browser
Open [http://localhost:5173](http://localhost:5173)
